# Minecraft Web Recreation

在当前工作区独立实现的第一人称方块生存游戏。技术栈为 JavaScript ES modules、Three.js、Vite 和 Web Audio；没有使用官方游戏源码、官方纹理、官方音频或其他工作区的内容。

## 启动

Windows 可双击 **`启动游戏.cmd`**；检测到已运行的本地游戏时会直接打开，不重复占用端口。命令行方式：

```powershell
npm ci
npm run dev
```

访问 **http://localhost:5173**。进入标题画面后，选择“创建新的世界”。生存模式从空背包开始；创造模式提供独立物品目录和飞行。点击“进入游戏”允许浏览器锁定鼠标，按 Esc 释放。

新世界可选择白天、黄昏或午夜开始。选项中“画质”在流畅、均衡、精细之间切换；默认均衡为6区块视距、1倍帧缓冲比例，不会暗中降分辨率。流畅档4区块/0.75倍/192粒子，精细档8区块/1.25倍/768粒子。创造目录新增四类怪物生成卵，可用于建造与场景体验；生存仍从空背包获得物资。

生产构建：

```powershell
npm run build
npm run preview
```

生产预览地址为 **http://localhost:4173**。`dist/` 可部署到普通静态 Web 服务器的根目录。游戏素材由本地代码生成，运行时不需要外部素材网站或 CDN。

## 生存开局

找到一棵树，长按左键破坏原木，走近拾取。按 E，将原木放入个人合成格制作木板；四块木板制作工作台，两块竖放木板制作木棍。将工作台放在地上，右键打开 3×3 合成格，制作木镐。用镐采集圆石，八块圆石制作熔炉。将可烧炼物放在上格、燃料放在下格，等待烧炼完成后取出右侧产物。

树木、工具、矿物、食物和容器通过同一套物品与世界数据流转，不存在独立于实际游戏状态的演示背包。夜晚的怪物会攻击玩家；食物、护甲、避难所和床可以改善生存条件。

## 已实现的系统

**世界与画面。** 确定性种子、动态加载和卸载的 16×16 区块、多生物群系、山地、河流、海洋、地下洞穴与矿脉、树木、植被和少量遗弃小屋。方块网格剔除不可见面，带逐顶点环境遮蔽、天空光和方块光；16×16 像素材质、最近邻采样、裂纹阶段、掉落物、碎屑粒子、第一人称手臂与工具动画。太阳、月亮、星空、立体云、昼夜循环、雨、天空渐变、距离雾以及水下和熔岩内的视距变化。

网格生成使用两个工作线程和不可变区块快照；旧世界或修改前的过时结果会丢弃，不能覆盖当前方块。只有贴图和四角光照完全相同的共面方块面才合并，贴图仍按每格 16×16 重复，不被拉伸。轴法线和整数光级使用无损紧凑属性，位置、贴图坐标与环境遮蔽保留原精度。火焰、水、熔岩和传送门的 32 帧纹理预先生成，通过 UV 帧切换播放，不在每帧重新上传整张地形贴图。

**移动与交互。** 20 Hz 固定节拍模拟与渲染插值，扫掠碰撞、重力、跳跃、疾跑、潜行防坠、半高台阶辅助、水中移动、梯子和创造飞行。准星射线选取、按工具与材料计算的挖掘时间、工具等级和耐久度、朝向状态、放置时的玩家/生物碰撞检查、门、床、半砖、楼梯、栅栏、箱子、工作台、熔炉。

**物品与生存。** 快捷栏、背包、拆分和堆叠、快速转移、护甲、副手、个人和工作台合成、配方书、烧炼与燃料、掉落物物理和拾取、生命值、饥饿与饱和度、经验和等级、摔落、溺水、灼烧、伤害无敌间隔、死亡掉落、重生和床重生点。

**生态和其他玩法。** 猪、牛、羊、鸡、僵尸、骷髅、苦力怕、蜘蛛，闲逛、追逐、近战、远程箭、日照灼烧、剪羊毛、动物繁殖和幼体。小麦种植与生长、锄地、骨粉、树苗生长、甘蔗、沙砾下落、有限水流与熔岩流、水和熔岩反应、水桶、TNT 引信与爆炸、弓箭、鸡蛋、黑曜石传送门及独立下界地形。

**普通敌对怪物。** 四类行为由固定节拍驱动：覆苔游尸（僵尸）追逐近战并在日照下燃烧；灰骨弓手（骷髅）蓄力、后退和横移，箭是真实投射物，发射前重新检查遮挡；苔壳爆灵（苦力怕）接近时引燃，失去视线可取消，引爆真实破坏地形；暮色织蛛（蜘蛛）根据实际局部亮度和挑衅状态决定敌对，白天的黑暗洞穴仍会攻击，具有扑跃和墙面攀爬。生成检查光照、24格玩家安全距离、实际支撑/空间和普通28、困难36的数量上限。寻路使用共享限预算A*和真实方块碰撞形状，支持绕墙、台阶跳跃、危险落差和熔岩避让，不在寻路时生成区块。怪物健康、火焰、引信、蓄力、目标记忆、累计坠落与生成卵持久化标记可保存；怪物有真实摔伤，落水和攀爬会清除累计；环境死亡不会远程给玩家战斗经验或成就。

**原创视觉与低成本光影。** 琥珀/铜绿的怪物材质、缠布外套、灰骨、苔壳发光核心与紫色织蛛壳均在代码中独立绘制；环境采用低频色块、岩层、木纹、矿石结晶和树叶簇。小面积眼睛/核心保留暗处辨识度。天空采用冷暖渐变，夜间轮廓适度可辨；保留真实天空光、方块光与逐顶点AO，增加太阳方向明暗、暖光细微变化、地下雾过渡，以及可关闭的水面Fresnel/波纹高光。没有额外全屏后处理、屏幕空间反射或级联阴影图；生物采用低成本接触阴影。

实体和地形现在使用一致的体素光照强度，避免怪物先乘昼夜再被Lambert二次压暗；夜间保持冷色、洞穴火把暖色，未照亮的身体仍是暗的，而不是整只生物全亮。原始截图和各视觉阶段记录在验收报告中。

**性能与资源。** 生物骨骼仍按真实位置动画，但共享部件使用实例化批次、视锥剔除和动态矩阵/颜色缓冲；不把远处怪物仅从统计中删掉。两个网格worker并行预热，区块邻域准备分帧执行；过时结果仍按版本丢弃。粒子预分配768个对象，材质取样缓存，掉落物使用空间分桶合并；地形列缓存分批淘汰而不整体清空。照明计算尽量放在顶点阶段，环境向量/颜色重用。Web Audio节点有64声音上限并在播放完成断开。只读诊断记录真实CPU阶段耗时和保存时长，与浏览器帧间隔分开报告。

碰撞形状使用冻结共享缓存；AI的布尔碰撞查询直接检查形状并提前返回，不再为每个节点构造完整障碍列表。优化与旧碰撞方法在数千组负坐标、部分方块和体型组合上逐一比较。区块诊断把持续保留的可见目标数targets和真正的未完成queued分开，避免把正常加载增长错报成泄漏。

**流体、农业与火焰。** 水与熔岩使用按游戏 tick 调度的有限流动，支持水源再生、源头移除后的退流、流向推力、水桶采集和冲毁装置后的真实掉落。流体四角高度同时用于渲染表面和眼睛浸没判定；落水当 tick 接触池底也会先判断水面，避免错误的干地摔落伤害。耕地有湿润和干燥状态；火可以由打火石点燃、手动扑灭、烧毁可燃材料并引燃 TNT。雨雪不穿过实体、玻璃、树叶、箱子或半砖屋顶，沙漠保持无降水，寒冷群系使用飘雪。

**红石。** 已实现红石粉信号衰减、跨区块连接和爬坡、拉杆、石按钮、压力板、红石火把反相、中继器方向与延时及侧向锁定、红石灯、红石门控、TNT 点火和普通活塞。活塞推动有数量上限与不可移动方块检查，实际移动方块并处理受挤压实体，而不是只播放模型动画。没有宣称支持原版完整红石体系。

**箱子。** 两个同朝向的相邻箱子可以组成大型箱子，提供同一个实时 54 格视图；两半底层仍各自拥有 27 格，拆掉一半只掉落该半的内容。两侧任一箱盖被阻挡时不能打开。箱体是空心模型，箱盖绕后侧铰链打开，并在关闭时复位；光照从实际相邻环境采样。合并关系、物品归属和拆分均支持跨区块和存档恢复。

**冒险终点。** 新版地形包含下界要塞与烈焰人刷怪笼、地下要塞和末地门框。末影人掉落珍珠，烈焰棒可制作烈焰粉，两者合成末影之眼；眼可投出寻找要塞，也可装入朝内的12个框架激活3×3门面。末地有安全出生平台、岛屿、黑曜石柱、10颗可摧毁水晶和真实末影龙战斗：盘旋、降落、分部位伤害、水晶治疗、龙息、死亡、经验、龙蛋和回程出口。降落高度按实际地形计算，战斗与物品能中途保存重载；胜利后返回主世界可继续游戏。创造模式也可使用正常目录建造入口。旧存档保留原地形生成版本，不会因加载而突然插入新要塞。

创造建门时，先围出3×3空地，每边放3个框架且朝向内部；当前实现请站在框架外侧朝内放置，再逐个右键装眼。战斗中先射掉水晶，带笼的先打开遮挡；龙降落时使用近战，箭不会伤害降落中的龙。末影珍珠有使用冷却与安全落点判定，生存使用后会受伤。具体实现与接手规则见根目录 `HANDOFF.md`。

**界面和持久化。** 标题与世界列表、新世界设置、创造物品目录、暂停、选项、进度、操作说明、死亡界面、真实渲染截图。IndexedDB 世界存档、定时自动保存、退出保存、JSON 导入和导出、页面离开时的小型应急快照。世界方块修改、容器、玩家状态、生物、掉落物、下落方块、引燃 TNT、飞行箭和经验球均由存档恢复。待处理的流体、重力与树叶衰减更新也会保存。保存使用隔离快照，后续游戏操作不会改写正在写入的数据；重叠的保存请求按顺序执行。

IndexedDB已升级为同数据库中的worlds/metadata双store，旧存档通过事务游标迁移；列表只读取轻量元数据，保存和删除在同一事务同步更新两者。遇到旧标签页阻塞升级时会提示关闭旧页，不删除存档。实玩自动保存复用缩略图，只在暂停等非模拟状态更新WebGL截图，避免每30秒强制GPU读回。刷新/退出快照语义和库存归还逻辑保持不变。

## 验收与日志

```powershell
npm test
npm run build
npm run test:e2e
npm run test:ui
npm run test:redstone
npm run test:fluids
npm run test:chests
npm run test:environment
npm run test:portals
npm run test:adventure
npm run test:streaming
npm run test:hostiles
npm run test:stress
npm run test:storage
npm run test:performance
# 或直接完成所有检查，并在真正的 dist 生产构建上跑浏览器验收：
npm run verify
```

`npm test` 自动发现并运行 `tests/` 下的全部 `*.test.js`，不会因新增文件而遗漏测试。目前采用单个顺序测试进程，避免本机 Node 隔离测试子进程曾出现的报告反序列化故障；断言和覆盖范围不因此删减。本项目实际使用的运行环境为 Node.js v24.16.0。

测试直接调用生产代码，覆盖种子、库存与合成、区块保存、射线、碰撞、移动速度、跳跃、潜行、伤害、光照、烧炼、并发保存、导入校验、流体、红石、大型箱子、工作线程快照、过期网格丢弃和 GPU 资源所有权。`tests/browser-smoke.mjs` 启动真实 Chromium，使用鼠标和键盘经过菜单进入游戏，从空背包生存开局完成砍树、拾取、个人合成、放置工作台、制作木镐与保存重载；另外通过创造模式正常物品目录检查建造、熔炉、TNT 重载后爆炸、世界导入导出与持物切换的几何资源数量。

`tests/interface-check.mjs` 检查四种实际窗口尺寸，包括 1280×720、640×480、480×320 和 400×720。它不仅截图，还检查物品栏是否超出面板、配方书是否超出视窗，以及栏位中心是否被其他控件遮挡。`tests/verify.mjs` 依次执行源码语法检查、全部测试、构建，在临时端口启动 **dist 生产预览** 后运行 `tests/test-suite.mjs` 清单中的全部浏览器验收：生存与背包、火焰农业、红石活塞、流体、水桶、大型箱子、连续区块加载及响应式界面。报告保留源码、测试脚本和生产文件 SHA-256、各阶段真实退出码、耗时与原始错误。

清单还包括下界门往返，以及 `tests/browser-adventure.mjs` 的末地全流程。冒险专项使用公开创造目录和真实键鼠，实际造框装眼、弓箭打水晶、剑近战、中途保存重载、击败后保存重载、进入出口回主世界及再次重载；不是从空包开始的完整生存通关记录。生存装眼/珍珠消耗、冷却、物资配方与一次奖励另有生产代码回归。完整验收结束时重新核对源码和dist哈希，并将报告及引用截图一同归档；运行中的专项会保存running检查点。

浏览器测试使用 `window.voxelDiagnostics` 的**只读快照**观察结果，不设置玩家位置、不注入物品、不写入世界、不使用测试专用游戏规则。失败会保留异常、实际最终状态、页面 HTML 和截图，不将失败伪装成通过。

验收产物位于 **`tests/artifacts/`**：

- `build.log`、`core-tests.log`：构建与核心测试输出。
- `browser-report.json`、`browser-run.log`：逐阶段结果和真实错误。
- `environment-report.json`、`redstone-report.json`、`fluids-report.json`、`chests-report.json`：各实际键鼠玩法验收。
- `portals-report.json`、`adventure-report.json`：下界往返与末地战斗/重载/返回全流程，截图以专项名开头。
- `streaming-current-report.json`：实际连续飞行的帧间隔、移动距离和工作线程状态，不以一个合格标记代替性能数据。
- `hostiles-report.json`、`stress-report.json`：夜间怪物、原型外观、真实战斗、保存刷新、连锁爆炸、实际地下水体、三档画质、长距离与长期资源检查。
- `performance-current-report.json` / `performance-baseline-report.json`：当前与历史基线的真实帧间隔；不能只凭draw calls减少声称全面提速。
- `storage-report.json`：独立真实IndexedDB组件回归，明确与实玩流程区分。
- `interface-report.json`、`interface-*.png`：窗口尺寸与可点击性检查。
- `final-verification.json`：最后一次完整验收的状态、退出码和对应源码哈希。
- `verification.html`：可直接打开的结果总览与原始截图画廊。
- `01-title.png` 等截图；失败时生成 `failure.png` 和 `failure.html`。

是否通过应以实际生成的日志与测试退出码为准。仅仅存在测试脚本不代表该版本已经通过测试。历次失败和成功的运行均保存在 `runs/`、`interface-runs/` 与 `verification-runs/` 子目录；顶层历史失败截图不能替代报告中的当前状态。浏览器自动化默认使用软件 WebGL，不能把其中的帧率当作所有机器上硬件加速性能的承诺。

玩家的速度、落地/潜行状态、坠落距离、燃烧与受伤计时也会保存。退出重载不会再重置空中速度、取消已累计的坠落距离或清除燃烧状态；旧存档缺少这些字段时仍可使用默认值加载。

## 实现边界

这不是 Mojang / Microsoft 官方客户端，也不声明与任何 Java 或基岩版本二进制、网络协议、世界种子或存档格式兼容。视觉资源和声音均是独立替代方案，不能等同于逐像素、逐采样的官方素材。

目前没有多人联机、完整红石体系（例如比较器、漏斗和全部准连接/时序行为）、附魔与药水体系、村民交易、完整村庄结构、末地城、龙复活流程，以及所有物品/生物/群系和官方客户端的全部细节。末地与末影龙已实现，但不是全部原版战斗行为的重现。世界建筑高度为128格；地形、流体、天空光边界、动物寻路和生物行为采用本项目实现，并非原版算法的逐行重现。方块光使用跨区块、考虑遮挡的局部传播，并与完整重算做逐字节对照。睡眠推进至清晨，没有完整卧床过场；火焰传播不覆盖原版全部燃烧规则。界面适配小窗口，移动和战斗仍以键盘鼠标为目标，不包含完整触屏操作。

普通敌对怪物覆盖这里列出的四类，不含所有原版怪物变种、装备随机化、完整阵营内斗等细节。寻路是有限距离、有限预算搜索，不保证任意迷宫或玩家建筑都能找到全局最优路；单个区块生成和光照操作仍可能超过分帧软预算。未实现完整方向投影阴影、体积云或真实光线追踪；软件WebGL高密度森林仍可能有明显帧时间尖峰。具体性能必须看本次实际报告，而不是由测试通过推定恒定60FPS。

主要存档存储在当前浏览器、当前站点地址的数据中。`localhost:5173` 与 `127.0.0.1:5173` 是不同站点，切换地址、端口、浏览器或清除网站数据会影响可见的世界列表。重要世界应使用游戏里的“导出”保存外部备份。本项目 JSON 存档不能当作官方 Minecraft 的世界目录直接打开。
